# Phase 1: Coverage gate - Plan 3: The tests job green on the runner

## Goal

The existing suite runs unattended on a macOS runner, and the fork-owned modules meet the accepted 85% lines and branches floor. This gap plan closes UAT item 4: the `tests` job at 4488777 (run 42335490351, macos-15) ended `21 failed, 571 passed, 11 skipped`, so the per-module gate step never ran. The plan makes each failure observable, takes the cause from CI evidence, fixes it there, and ends with a pushed `personal` commit whose `tests` job passes and uploads a `coverage.json` showing all 7 modules meeting 85. That end is conditional on Task 4's evidence explaining every cluster; where it does not, the plan ends at Task 8 with UAT item 4 still failed and its evidence recorded for a further gap plan.

## Must be true when done

- When a fake server in `tests/test_launchers.py` or `tests/test_quit.py` fails to start, the failure message shows that server's own output and the launcher's `server.log`. On the runner, the same logs are uploaded as an artifact when the job fails.
- The page tests' failure messages report the conditions they ran under: the page's reduced-motion state and `lowFx` for `tests/test_page_notch.py`, and the browser's own frame rate next to the page loop's for `tests/test_page_idle.py`.
- Each of the three failure clusters has a cause read from a CI run's evidence, and a fix made at that cause. No test is skipped, exempted or loosened for CI except where the plan says why the test was measuring the runner and not the app.
- On a pushed `personal` commit, the `tests` job passes. Its `coverage.json` artifact gives `<file>: lines: … meets 85` and `<file>: branches: … meets 85` for all 7 `include` files, and its `-rs` summary still shows only `slow tier: set VOID_SCENES=1` skips (AC3 and AC5, ci: tests).
- Locally on Slate, the two accepted commands from `.github/cadence/coverage-policy.json` still exit 0 with the same 14 meets lines, and `planning.mjs test-policy check --root .` still prints `"gate_found":true` (UAT items 2, 3 and 5 stay passing).
